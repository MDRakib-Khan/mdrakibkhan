# 🚀 Portfolio Website

Personal portfolio website of **Md. Rakib Khan**, built to showcase projects, skills,
education, and experience in **Artificial Intelligence, Game Development, and Web Programming**.

🌐 **Live Portfolio:**  
https://mdrakibkhan.vercel.app

---

## 📌 About the Project

This portfolio website represents my academic journey, technical skill set,
and hands-on experience with programming and development projects.
The goal of this website is to present my work in a clean, interactive,
and professional manner.

It highlights my interest in:
- Artificial Intelligence
- Game Development (2D & 3D concepts)
- Web Application Development

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **jQuery**

---

## ✨ Features

- Fully responsive design  
- Clean and modern user interface  
- Smooth scrolling and animations  
- Dynamic typing text animation  
- Skills and abilities section  
- Education and experience timeline  
- Projects showcase section  
- Contact form integration
